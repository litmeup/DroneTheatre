## 👩‍🎓 Как студенту развернуть проект шаг за шагом

Ниже инструкция для локального запуска проекта.
Подходит для **Python 3.13.1** (и в целом для Python 3.10+).

---

### 1. Установи нужное

1. У тебя должен быть установлен:
   - Python 3.13.1
   - MySQL Server
   - Git (по желанию, если клонируешь репозиторий)

2. Скачай проект:
   - либо через `git clone`:
     ```bash
     git clone https://github.com/<USERNAME>/<REPO_NAME>.git
     cd <REPO_NAME>
     ```
   - либо скачай `.zip` с GitHub и распакуй.

---

### 2. Создай и активируй виртуальное окружение

В папке проекта:

```bash
python -m venv venv
````

Активируй окружение:

* **Windows (cmd):**

  ```bash
  venv\Scripts\activate
  ```
* **macOS / Linux / WSL:**

  ```bash
  source venv/bin/activate
  ```

Если всё ок, в начале строки терминала появится `(venv)`.

---

### 3. Установи зависимости

```bash
pip install -r requirements.txt
```

Если файл `requirements.txt` отсутствует, спроси его у преподавателя или установи минимум:

```bash
pip install Flask pymysql
```

---

### 4. Создай базу данных и импортируй дамп

1. Запусти MySQL-клиент:

   ```bash
   mysql -u root -p
   ```

2. Внутри MySQL создай базу:

   ```sql
   CREATE DATABASE drone_theatre
     CHARACTER SET utf8mb4
     COLLATE utf8mb4_unicode_ci;
   EXIT;
   ```

3. Импортируй дамп (файл `dump.sql` должен лежать в папке проекта):

   ```bash
   mysql -u root -p drone_theatre < dump.sql
   ```

---

### 5. Настрой подключение к БД

Открой файл `app.py` и найди блок настроек БД:

```python
DB_HOST = "localhost"
DB_USER = "root"
DB_PASS = "ваш_пароль_от_mysql"
DB_NAME = "drone_theatre"
```

Подставь свой пароль от MySQL.

---

### 6. Запусти приложение

В активированном виртуальном окружении:

```bash
python app.py
```


После запуска:

* открой в браузере: **[http://127.0.0.1:5000/](http://127.0.0.1:5000/)**
* должна появиться главная страница «Театр одного дрона».

---

### 7. Если что-то не работает

Проверь:

* активировано ли виртуальное окружение (`(venv)` в командной строке);
* установились ли все зависимости (`pip install -r requirements.txt`);
* правильно ли указаны настройки БД в `app.py`;
* база `drone_theatre` существует и в неё импортирован `dump.sql`.

Если ошибка остаётся — сделай скрин терминала и/или текста ошибки и пришли преподавателю.
